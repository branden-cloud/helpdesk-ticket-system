# Help Desk Ticket System

A web-based ticketing system that simulates real-world IT support workflows.

## Features
- Create and manage support tickets
- Categorize issues by type
- Track ticket status
- Search and filter tickets
- Dashborad with ticket metrics

## Tech Stack
- HTML
- CSS
- JavaScript
- localStorage

## Purpose
Built to demonstrate IT support workflows and front-end development skills.

## Status
Completed and ready for deployment
